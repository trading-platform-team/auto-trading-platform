# AI 이상거래 탐지

## 구조

```
collector ──> Kafka(stock.price) ──> ai 컨테이너 ──┬──> Kafka(stock.anomaly)
                                                   ├──> Redis anomalies  ──> backend GET /anomalies
                                                   └──> Redis alerts     ──> 통합 알림 (주문 알림과 함께)
```

시세 1건이 들어올 때마다 두 가지 방식으로 동시에 검사한다.

| 방식 | 내용 | 장점 | 한계 |
|---|---|---|---|
| 룰 기반 | 거래량 3배↑, 가격 ±3%↑, 호가 불균형 0.6↑ | 이유가 명확, 학습 불필요 | 기준 미만의 이상은 못 잡음, 종목마다 같은 기준 |
| AI 모델 (LOF) | 종목별로 평소 시세 패턴을 학습해 벗어나는 정도를 점수화 | 기준을 정하지 않아도 됨, 종목별 적응, 복합 이상 탐지 | 학습 데이터(100건)가 쌓여야 동작 |

둘 다 잡으면 경보 수준 `high`, 하나만 잡으면 `medium`.

## 입력 특징 (anomaly/features.py)

| 특징 | 의미 |
|---|---|
| ret | 직전 대비 수익률(%) |
| vol_ratio | 최근 20건 평균 대비 거래량 배수 |
| imbalance | (매수잔량 − 매도잔량) / 전체잔량 |

### 특징 선택: volatility 제외

처음에는 최근 수익률 표준편차(volatility)도 특징으로 넣었다. 그런데 화면에서 시연해 보니
가격 급변이 한 번 생기면 그 뒤 20건 동안 volatility가 계속 높게 남아서
같은 종목에 "변동성 이상" 경보가 연달아 뜨는 문제가 있었다.

| 특징 | 학습 데이터 | Precision | Recall | 오탐(평균) |
|---|---|---|---|---|
| 4개 (volatility 포함) | 100건 (실시간 설정) | 0.64 | 0.98 | 257건 |
| **3개 (volatility 제외)** | **100건** | **1.00** | **0.99** | **0건** |
| 4개 | 1,000건 | 0.99 | 1.00 | 0.4건 |
| 3개 | 1,000건 | 1.00 | 1.00 | 0건 |

volatility는 이미 다른 특징(ret)에 담긴 정보를 뒤늦게 반복할 뿐이라 제외했다.

## 모델 선택 과정

처음에는 Isolation Forest를 사용했으나, 학습 범위를 벗어난 값(예: 평소의 8배 거래량)을
경계값과 비슷하게 취급해서 놓치는 문제가 있었다. 비지도 모델 3종을 같은 조건에서 비교했다.

- 데이터: 정답 라벨이 있는 합성 시세 4,000건 × seed 10개 (anomaly/synthetic.py)
- 학습: 앞 1,000건, 평가: 나머지 약 3,000건
- 실행: `cd ai && python evaluate.py --seeds 10`

| 모델 | Precision | Recall | F1 |
|---|---|---|---|
| 룰 기반 | 1.00 | 0.75 | 0.85 |
| Isolation Forest | 0.88 | 0.88 | 0.87 |
| Elliptic Envelope | 0.89 | 0.93 | 0.90 |
| **LOF (채택)** | **1.00** | **1.00** | **1.00** |

### 이상 종류별 탐지율

| 종류 | 룰 | LOF |
|---|---|---|
| 거래량 급증 | 0.98 | 1.00 |
| 가격 급변 | 1.00 | 1.00 |
| 호가 불균형 | 1.00 | 1.00 |
| **복합 (거래량 2~2.8배 + 가격 1.5~2.5% + 호가 쏠림 0.35~0.5)** | **0.03** | **1.00** |

복합 이상은 각 지표가 룰 기준 미만이라 룰로는 거의 잡히지 않지만,
세 지표가 동시에 평소와 다르게 움직이는 패턴을 LOF는 모두 잡아냈다.
이것이 룰 기반에 AI 모델을 더한 이유다.

### LOF 설정

- n_neighbors = 20, 특징 표준화(StandardScaler)
- LOF 점수 > 3.0 이면 이상 (1 근처가 정상). 점수 임계값 2.0 / 2.5 / 3.0 / 4.0 을 비교해서 정확도와 재현율이 가장 안정적인 3.0 선택
- 종목별 100건이 모이면 첫 학습, 이후 200건마다 최근 2,000건으로 재학습
- 학습된 모델은 `ai-models` 도커 볼륨에 저장 → 컨테이너를 재시작해도 유지
